IP Discovery Tool
Uma ferramenta simples em Python para descobrir:

Endereço IP Local
Endereço IP Público
Funcionalidades
✅ Descoberta do IP da máquina local

✅ Descoberta do IP público através de API

✅ Tratamento básico de erros

✅ Fácil de usar

Instalação
Clone o repositório:

git clone https://github.com/renancristianobn-del/ip-discovery-tool.git
Entre na pasta:

cd ip-discovery-tool
Crie um ambiente virtual:

python -m venv venv
Ative o ambiente virtual:

Windows
venv\Scripts\activate
Linux/Mac
source venv/bin/activate
Instale as dependências:

pip install -r requirements.txt
Uso
Execute:

python ip_discovery.py
Saída esperada:

========================================
      IP Discovery Tool
========================================
IP Local: 192.168.1.10
IP Público: 189.xxx.xxx.xxx
